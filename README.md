# 纳斯达克 100 跨境基金监控

一个面向纳斯达克 100 相关基金的网页监控工具，集中展示场内 ETF 溢价、场外 QDII 申购额度、基金公告、净值表现及 QQQ 行情。

项目采用纯静态单页前端和 Cloudflare Worker 后端，不依赖前端框架，适合直接部署到静态托管服务并配合 Worker 使用。

## 主要功能

### 场内 ETF

- 跟踪 12 只纳斯达克 100 场内 ETF。
- 展示场内价格、实时估值、溢价率、基金规模和费率。
- 支持按溢价率、规模、费率等字段排序。
- 展示历史行情、年度表现和历史溢价。
- 交易时段约每 20 秒刷新，非交易时段降低刷新频率。

场内实时数据按以下顺序回退：

1. 东方财富 ETF 行情，同一快照内取得价格和 IOPV。
2. Tinyright，同源价格和估值。
3. HaoETF，仅用于已确认覆盖的产品。
4. Cloudflare 最近有效缓存。

系统不会将不同平台的价格和估值拼接计算，溢价率统一由 Worker 使用 `价格 / 估值 - 1` 计算。

### 场外 QDII

- 覆盖 41 个人民币纳斯达克 100 QDII 份额。
- 单独覆盖广发基金 000055、006480 两个美元份额。
- 展示代销额度、直销额度、申购状态、公告校验、净值、日涨跌、跟踪误差、费率和年度收益。
- 支持公司聚合排序和单字段排序。
- 支持打开基金公告、费率详情及历史净值。

人民币份额的数据口径：

- 当前额度以安鑫乐 QDII 额度日报为主数据源。
- 基金管理人公告作为独立校验及未来生效预警来源。
- Worker 检查 17 个基金主代码和 8 个特殊份额代码的额度公告。
- 新公告尚未生效时只展示预警，不提前改变当前额度。
- 对未验证或部分验证的产品按需向后查询历史公告。

美元份额的数据口径与人民币不同：

- 不使用人民币额度日报，也不将人民币额度换算成美元。
- 申购状态和限额仅根据基金管理人公告解析。
- 只有公告明确使用“美元”披露限额时才显示美元额度。
- 净值、日涨跌及年度收益仍从东方财富基金净值数据读取。

### QQQ

- 展示 QQQ 最新行情及基础资料。
- 展示历史累计涨跌幅和年度业绩。
- 支持手动刷新 QQQ 数据。

## 场外缓存与刷新机制

场外数据按上海自然日缓存：

- 当天第一次打开时获取最新数据并生成当天缓存。
- 当天后续打开直接读取缓存，避免重复请求大量上游页面。
- 人民币额度和公告结果优先写入 Cloudflare D1 的 `otc_daily_cache` 表。
- 未配置 D1 时退化为 Worker Cache API。
- 美元份额、净值和跟踪误差分别维护当天缓存。
- 上游获取失败时优先保留最近一次有效数据，不用失败结果覆盖有效缓存。

点击“刷新额度与公告”时会：

1. 强制刷新人民币额度日报。
2. 重新检查人民币基金额度公告。
3. 单独刷新两个美元份额的额度公告。
4. 更新当天的额度缓存。

手动额度刷新不会强制刷新净值、跟踪误差和历史业绩，前端会保留这些低频字段。

页面启动时先请求场内行情，完成后再预热场外数据，避免当天首次场外刷新影响场内实时数据。

## 项目结构

```text
nasdaq100-monitor/
├─ index.html
├─ worker/
│  └─ worker_nasdaq100_etf_v3_28_qqq_daily_fix_utf.js
├─ 历史/
│  └─ 各版本页面及 Worker 备份
└─ README.md
```

- `index.html`：完整网页、样式、交互和图表逻辑。
- `worker/`：Cloudflare Worker 数据聚合、解析、缓存及 API 路由。
- `历史/`：旧版本留档，不参与当前页面运行。

## Worker API

| 接口 | 用途 |
| --- | --- |
| `/health` | Worker 状态、功能和 D1 绑定检查 |
| `/api/premiums` | 12 只场内 ETF 实时溢价 |
| `/api/eastmoney-test` | 东方财富 ETF 数据源诊断 |
| `/api/premium-history` | 场内 ETF 历史溢价 |
| `/api/history-status` | D1 历史数据状态 |
| `/api/otc-funds` | 人民币场外额度及公告校验 |
| `/api/otc-funds?refresh=1` | 强制刷新人民币额度及公告 |
| `/api/otc-usd-funds` | 两个美元份额额度及公告 |
| `/api/otc-fee` | 场外基金费率详情 |
| `/api/otc-nav-summary` | 场外基金净值及年度收益摘要 |
| `/api/otc-tracking-summary` | 场外基金年化跟踪误差 |
| `/api/fund-history` | 基金历史净值 |
| `/api/annual` | 年度业绩 |
| `/api/qqq` | QQQ 行情和历史表现 |

## 部署

### 1. 部署 Worker

将以下文件部署为 Cloudflare Worker：

```text
worker/worker_nasdaq100_etf_v3_28_qqq_daily_fix_utf.js
```

如需使用每日额度缓存和场内历史记录，请创建 Cloudflare D1 数据库，并将 Worker 绑定名称设置为：

```text
DB
```

相关数据表会在首次使用时自动创建。

可选的 Cron 建议配置为工作日北京时间 15:05，对应 UTC：

```text
5 7 * * 1-5
```

Cron 用于保存交易日场内溢价历史。

### 2. 配置前端

修改 `index.html` 中的 Worker 地址：

```js
const WORKER_BASE = "https://你的-worker.workers.dev";
```

### 3. 部署页面

`index.html` 是独立静态页面，可以部署到 GitHub Pages、Cloudflare Pages 或其他静态托管服务，也可以直接在本地浏览器打开。

本项目使用 GitHub Pages 时的推荐设置：

1. 打开仓库的 `Settings → Pages`。
2. 在 `Build and deployment` 中选择 `Deploy from a branch`。
3. 分支选择 `main`，目录选择 `/ (root)`。
4. 保存并等待部署完成。

部署成功后的公开访问地址为：

```text
https://jydragons.github.io/nasdaq100-fund-monitor/
```

## 数据与风险说明

- 页面数据来自第三方公开行情、基金页面及基金公告，可能存在延迟、接口调整或解析失败。
- 实际申购状态、每日额度和费率应以销售渠道及基金管理人最新公告为准。
- 本项目仅用于数据整理和个人研究，不构成任何投资建议。
